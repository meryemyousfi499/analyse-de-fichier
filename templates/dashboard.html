    File d'attente d'analyse
    
      
    
        La surveillance sépare deux files : les nouveaux
        téléchargements (priorité haute, traités FIFO dès qu'ils se
        stabilisent) et les fichiers déjà présents sur la
        machine au démarrage (priorité basse, traités en arrière-plan sans
        jamais bloquer un nouveau téléchargement).

    Sandbox dynamique
    
      
    
        Tout fichier jugé élevé ou critique par
        l'analyse statique ci-dessus est automatiquement mis en file ici pour
        un test comportemental réel : il est ouvert/exécuté dans une machine
        virtuelle jetable distante (via l'API Hybrid Analysis), ce que le
        reste du pipeline ne fait jamais.
      
    

      
    
        Aucune clé HYBRID_ANALYSIS_API_KEY n'est configurée : les
        fichiers suspects sont listés ci-dessous mais ne sont pas encore
        soumis au test sandbox. Configurez la clé (gratuite sur
        hybrid-analysis.com)
        puis redémarrez le serveur, ou soumettez manuellement une entrée
        ci-dessous une fois la clé ajoutée.
